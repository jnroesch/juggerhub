# Contract: the two root files the browser depends on (054)

This feature exposes no API. Its "interface" is two static files at the site root plus the
links that point at them from the entry page. Everything below is identical in local (compose),
Dev and Prod — the same built image serves it.

## `GET /sw.js` — the service worker script

| Aspect | Contract |
|---|---|
| Status | `200` when present; **`404` when absent** — never `200` with `index.html` (FR-009) |
| `Content-Type` | `application/javascript` (nginx `mime.types` `js`) |
| `Cache-Control` | `no-cache` (nginx `add_header … always`) |
| `ETag` / `Last-Modified` | nginx defaults (so the `no-cache` re-check is a `304`) |
| Body | ECMAScript; **contains none of** `addEventListener('fetch'`, `caches.`, `importScripts(` (FR-007, FR-011; guard spec) |
| Scope it may claim | `/` (root placement; no `Service-Worker-Allowed` needed) |
| Registered by | `registerServiceWorker()` with `{ scope: '/', updateViaCache: 'none' }`, once per visit, after `load`, errors swallowed (FR-008) |
| Behaviour | `install` → `skipWaiting()`; `activate` → `clients.claim()`; **nothing else** in this feature. `push` / `notificationclick` are #308 |

## `GET /manifest.webmanifest` — the installable description

| Aspect | Contract |
|---|---|
| Status | `200` when present; **`404` when absent** — never `index.html` |
| `Content-Type` | `application/manifest+json` (set by `default_type` in the location — the image's `mime.types` has no `webmanifest` entry) |
| `Cache-Control` | `no-cache` |
| Linked from | `<link rel="manifest" href="manifest.webmanifest">` in `index.html` (FR-003) |

### Manifest shape

```json
{
  "name": "JuggerHub",
  "short_name": "JuggerHub",
  "id": "/",
  "start_url": "/",
  "scope": "/",
  "display": "standalone",
  "background_color": "#FBF8F3",
  "theme_color": "#FFFFFF",
  "icons": [
    { "src": "icons/icon-192.png",          "sizes": "192x192", "type": "image/png", "purpose": "any" },
    { "src": "icons/icon-512.png",          "sizes": "512x512", "type": "image/png", "purpose": "any" },
    { "src": "icons/icon-maskable-192.png", "sizes": "192x192", "type": "image/png", "purpose": "maskable" },
    { "src": "icons/icon-maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]
}
```

Rules the guard spec enforces:

- `display === "standalone"`, `start_url === "/"`, `scope === "/"`, `id === "/"`.
- `background_color === "#FBF8F3"` (DESIGN `surface-page` / `sand-0`) and
  `theme_color === "#FFFFFF"` (DESIGN `surface-card`). Changing a token in DESIGN.md means
  changing it here, and the test says so.
- **No `description`, no `screenshots`, no `shortcuts`, no `lang`** — every one of those is a
  string a browser would show (FR-005: zero copy).
- Every `icons[].src` resolves to a file under `apps/web/public/`, is a PNG, and its IHDR
  width × height equals `sizes`. `purpose` values are `any` or `maskable`, never combined.

## Entry-page links (`index.html`)

| Element | Value | Why |
|---|---|---|
| `<link rel="manifest">` | `manifest.webmanifest` | FR-003 — every route installable |
| `<meta name="theme-color">` | `#FFFFFF` | same token as the manifest's `theme_color`, for the browser-tab context |
| `<link rel="apple-touch-icon">` | `icons/apple-touch-icon.png` (180×180, opaque) | iOS takes the Home Screen icon from here, not the manifest, and paints transparency black |
| `<meta name="viewport">` | **unchanged** (`width=device-width, initial-scale=1`) | research R6 — no `viewport-fit=cover` |

## Icon files (`apps/web/public/icons/`)

| File | Size | Source | Alpha | Purpose |
|---|---|---|---|---|
| `icon-192.png` | 192×192 | `favicon.svg` | transparent corners | manifest `any` |
| `icon-512.png` | 512×512 | `favicon.svg` | transparent corners | manifest `any` |
| `icon-maskable-192.png` | 192×192 | `icon-maskable.svg` | opaque | manifest `maskable` |
| `icon-maskable-512.png` | 512×512 | `icon-maskable.svg` | opaque | manifest `maskable` |
| `apple-touch-icon.png` | 180×180 | `icon-maskable.svg` | opaque | `<link rel="apple-touch-icon">` |
| `icon-maskable.svg` | — | authored | — | source only; not referenced by the manifest |

Regenerated by `node frontend/tools/render-pwa-icons.mjs`; output committed.

## What is explicitly NOT part of this contract

- Any push subscription, VAPID public key, permission request, or `push`/`notificationclick`
  handling — #308.
- Any caching, precaching, offline page, or `fetch` interception — forbidden (FR-011).
- Any backend endpoint, ingress rule, Terraform resource or environment variable — none change.
